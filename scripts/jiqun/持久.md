# jq 持久化安装说明

如果远端容器关闭后会清掉 `/usr/bin`，那么装在 `/usr/bin/jq` 的 `jq` 每次新开容器都要重新安装。

更好的做法是把 `jq` 放到持久目录，比如：

```bash
mkdir -p "$HOME/bin"

curl -k -L \
  -o "$HOME/bin/jq" \
  https://github.com/jqlang/jq/releases/download/jq-1.7.1/jq-linux-amd64

chmod +x "$HOME/bin/jq"
export PATH="$HOME/bin:$PATH"
```

确认：

```bash
which jq
jq --version
```

如果 `$HOME` 也是持久的，就不用每次重下。也可以放到确定持久的 bucket/work 目录，例如：

```bash
/home/ma-user/work/bucket-wulan-green/chenyanbo/bin/jq
```

然后在 `run-hfd.sh` 前面加：

```bash
export PATH="/home/ma-user/work/bucket-wulan-green/chenyanbo/bin:$PATH"
```
