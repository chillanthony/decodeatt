# 模型下载 HTTP 000 排障

`HTTP 000` 不是服务器返回码，而是 `curl` 在收到 HTTP 响应前就失败了，通常是代理、DNS、连接超时或 SSL 证书问题。

此前访问官方源已经出现代理 `504 Gateway Timeout`，因此先切换到 Hugging Face 镜像并绕过代理：

```bash
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY \
    -u http_proxy -u https_proxy -u all_proxy \
    HF_ENDPOINT=https://hf-mirror.com \
    scripts/jiqun/run-hfd.sh
```

如果仍然出现 `HTTP 000`，运行下面的命令查看真实原因：

```bash
curl -vkL https://hf-mirror.com/api/models/deepseek-ai/DeepSeek-R1-Distill-Llama-8B
```

如果该命令加上 `-k` 后可以成功，说明是 SSL 证书验证问题，需要给 `hfd.sh` 中的 `curl` 增加 `-k`，并给 `wget` 增加 `--no-check-certificate`。
