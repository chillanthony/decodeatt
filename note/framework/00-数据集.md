**Long Context**

| 数据集 | 主要用途 |
|---|---|
| LongBench / LongBench v2 | 长文档理解、跨段推理、长上下文 QA，是最常用的长上下文综合评测之一。 |
| RULER | 可控长度的长上下文压力测试，常用来测模型真实可用 context size。 |

**Long Session / Long-Term Memory**

| 数据集 | 主要用途 |
|---|---|
| LoCoMo | 长程多 session 对话记忆，评估跨会话信息保持、事件总结和时间推理。 |
| LongMemEval | 长期聊天记忆评测，覆盖信息抽取、多 session 推理、知识更新和拒答。 |

**Agentic Harness / Long-Horizon Agent**

| 数据集 | 主要用途 |
|---|---|
| SWE-bench | 软件工程 agent 最常用评测，基于真实 GitHub issue，考察代码修改和测试通过。 |
| WebArena | Web agent 常用评测，在真实网站环境中完成多步浏览、表单、检索和操作任务。 |
