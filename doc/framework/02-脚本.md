# 实验脚本注意事项

## 当前脚本含义

`scripts/cluster/run_arm.sh aime24 rkv 1536` 表示：在 AIME 2024 的 30 道题上，用 RKV 策略、1536 KV budget 进行多 GPU 评测，每题采样 4 个答案，最多生成 32768 tokens。

## 每次写脚本要注意

- `RUN_NAME` 必须唯一，建议包含数据集、策略、budget、采样数和关键变量。同名实验会清空旧日志并覆盖结果。
- 脚本命令行参数会覆盖 YAML 中的同名配置，修改前先确认参数的实际来源。
- 区分实验参数和性能参数。显存不足时优先减小 `BATCH_SIZE`，不要误改 `NUM_RETURN_SEQUENCES`。
- 正式实验前先用 `N=1 MAX_NEW=256` 跑 smoke test。
- 检查模型和数据集缓存；该脚本强制离线模式，缓存缺失会直接失败。
- 默认使用所有可见 GPU，每张 GPU 加载一份完整模型。可用 `CUDA_VISIBLE_DEVICES` 限定 GPU。
- 同机并行运行多个实验时，为每个实验设置不同的 `MASTER_PORT`。
- 正式实验记录 Git commit、配置、seed、模型路径和 GPU 信息。`brief` 只保存汇总；需要分析具体回答时使用 `LOG_MODE=full`。

## 不同实验可修改的参数

### 会改变实验定义

- `MODEL`：模型。
- `CONFIG`：完整配置文件。
- `DATASET` / `N`：数据集和题目数。
- `ARMS`：策略和 KV budget，如 `rkv@1536`。
- `MAX_NEW`：最大生成长度。
- `NUM_RETURN_SEQUENCES`：每题的采样数。
- YAML 中的 `temperature`、`top_p`、`seed`、eviction 参数和 RKV 内部参数。

### 主要影响速度和显存

- `BATCH_SIZE`：同一道题一次并行生成的候选数。
- `PROBLEM_BATCH_SIZE`：一次并行处理的题目数。
- `NPROC_PER_NODE`：使用的 GPU 数。
- `CUDA_VISIBLE_DEVICES`：指定可见 GPU。
- `MASTER_PORT` / `TIMEOUT_MINUTES`：分布式通信配置。

`NUM_RETURN_SEQUENCES=4, BATCH_SIZE=2` 表示每题仍生成 4 个答案，但分两批生成。

## 启动示例

```bash
RUN_NAME=aime24_rkv_b2048_s8_seed1 \
NUM_RETURN_SEQUENCES=8 \
BATCH_SIZE=2 \
NPROC_PER_NODE=4 \
MASTER_PORT=29501 \
bash scripts/cluster/run_arm.sh aime24 rkv 2048
```
